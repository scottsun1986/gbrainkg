# v55.0 — 文档入库、完整表事实与 QA 生命周期大版本

本版本基于 `7efe4a1` 的入库优化实施与统一验收，完成 [实施清单](入库优化实施待办清单-2026-10-09.md) 的 22/22 项。具体证据和测试边界见 [验收报告](入库优化实施验收报告-2026-10-09.md)。本说明记录源码成果与发布要求；演示及生产的实际发布结果以发布后核验为准。

## 主要变更

- Excel 保留原始类型、0/false、日期、错误与公式缓存，区分合并锚点和展示值。大表使用完整流式事实产物与有界预览，支持完整授权表过滤/聚合、批次恢复和覆盖率展示。
- PDF、Word、PPT 和图片统一正文/图片资产、页/对象位置与失败单元重试；新增旧版 PPT、WebP/TIFF/BMP、多帧图片支持。Markdown 资源包关联相对图片，并保留安全读取和版本授权。
- ZIP/TAR 增加逐项受理、跳过、失败与进度清单，处理重名、规范路径、安全限额和重试；嵌套包明确报告不展开。
- QA 支持 CSV/XLSX/JSONL 显式字段映射和预览、稳定 ID、候选审核与版本 CAS 发布；时间、适用范围和来源版本参与裁决，来源撤权/删除使派生 QA 失效。
- 页面展示真实正文与系统骨架计数、基础索引/覆盖/可选增强状态、失败批次重试。共享 Worker 增加资源预算、公平调度、背压、可终止原生子进程与实例/版本绑定缓存。
- 资产、事实、QA、批次沿用应用层权限与不可变版本生命周期；访问入口已登记于 [应用层访问边界清单](RLS-BOUNDARIES.md)。检索保持语料无关，实例继续共享单一 Parser Worker。

## 验证成果

- `pnpm test`：182 个测试套件通过、1 个既有套件跳过；**1,583 passed / 5 skipped**。API/Web 类型、lint、构建通过；Web lint 有 120 条 warning、0 error。
- Parser：**78 passed**、4 个 subtests passed，Ruff/mypy 通过。实际格式样本包含 PDF、图片、多帧 TIFF、PPTX 和本地 LibreOffice `.ppt` 冷转换。
- 隔离 API/数据库/本地 Worker 验收覆盖万行完整表聚合、权限拒绝、局部重试与新版本、QA 候选审核、包内图片资产授权、来源撤权及删除。浏览器 fixtures 验收页面错误为 0。
- 独立 Worker 大表 benchmark：10k 行冷/暖 **2.422/2.105 s**，峰值 RSS 55,072 KiB；100k 行冷/暖 **23.279/20.507 s**，峰值 RSS **71,544 KiB（约 70 MiB）**。两档均保留完整事实产物，只载入 200 行预览、1,000 行批次。

上述大表数字是 Worker 独立 benchmark，并非端到端 API 时延。最终 10,001 行隔离闭环解析/发布为 3.01 s、完整聚合 313 ms；优化后没有重复 100k 行端到端闭环。确定性 embedding 和测试队列不衡量线上模型质量或 Redis 吞吐；OCR/VLM/Docling 外部模型质量、成本、并发生产负载及单一混合格式压力作业未测量。

## 发布与回滚要求

新增 `20261009000000_ingestion_import_manifest` 为扩展迁移，不删除历史原件/Markdown/版本。旧应用可继续读取旧 Markdown；应用回滚不撤销数据库迁移。

生产发布及回滚在既有共享 Parser 虚拟环境中按 `requirements.lock.txt` 增量同步 NumPy、PyMuPDF、Pillow，不清空环境、不全量重装开发工具或本地模型。Python 3.11+ 当前 pin 为 NumPy 2.4.6、PyMuPDF 1.28.2、Pillow 12.1.1；NumPy 对 Python 3.10 按锁文件选择 2.2.6。pip 临时文件放在已挂载 `/data`，关闭下载缓存。旧版 PPT 需要 soffice 和已安装的 `libreoffice-impress-nogui` 或 `libreoffice-impress`；脚本在缺失时中止，系统包由运维检查磁盘和现有 headless 套件兼容后安装。

发布仍须经过测试环境、发布前快照、迁移与依赖检查、服务重启及健康验证；生产按明确授权执行。此处没有宣称演示或生产已成功发布。
