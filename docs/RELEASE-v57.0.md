# GBrainKG v57.0 — 全链路实测与质量、安全、韧性大版本

发布日期：2026-10-10。基线 `81c7285`（v56.0），来源为一次覆盖入库、查询、权限的本地全量实测与缺陷修复。

## 为什么发这个版本

此前版本的变更以设计评审与专项测试为依据，缺少一次"把所有文档格式都真的传进去、把答案都拿去和原文对账"的端到端实测。本版本先用 36 份语料覆盖全部 19 种支持格式与压缩包、59 道带标准答案的问题、权限与并发边界跑通全链路，再据此修复暴露出的缺陷。共修复 9 类问题，其中 3 项为高优先级（压缩包完全不可用、非文本格式全部解析失败、批量上传大面积失败），3 项影响回答可信度（引用噪声、弱拒答、错误提示不可操作）。

## 变更清单

### 入库与解析

| 项 | 变更 | 生效条件 |
| --- | --- | --- |
| A01 | 新增迁移 `20261010000000_residual_rls_cleanup`：幂等禁用全库 RLS（含 FORCE）、删除残留策略、补齐运行时角色 `llmwiki_app` 的表/序列授权与默认权限 | 迁移 |
| A02 | `heal-rls-no-policy-tables.sh` 改指新迁移。原迁移对未评审表 fail-closed，无法修复 gbrain bootstrap 重新开启 RLS 的新表 | 自动 |
| A03 | 解析调用对 503 背压做有限重试（最多 5 次，遵循 `Retry-After`，上限 30 秒）；非 503 不重试 | 自动 |
| A04 | 不支持的文件类型由 400 统一为 415（与 parser 一致），错误信息列出支持的扩展名 | 自动 |
| A05 | 无扩展名文件按 parser 既有行为补 `.md`，消除两侧规则不一致 | 自动 |
| A06 | 解析失败由 `Parser operation failed (BadZipFile)` 改为可操作文案（损坏/加密/编码三类），保留原有敏感信息脱敏 | 自动 |
| A07 | Excel 纯日期不再输出 `2025-03-01T00:00:00`；含时间的仍保留完整 ISO | 自动 |
| 运维 | `deploy-prod.sh` 健康检查新增 parser 鉴权探测。此前不校验共享 token，两侧缺失时解析全量失败却仍判定发布成功 | 自动 |

### 回答质量

| 项 | 变更 | 生效条件 |
| --- | --- | --- |
| B01 | 新增 `supporting-citations`：未被 reranker 打分的条目不再作为依据；测量分远低于最高分的按相对阈值剔除（不依赖供应商绝对分制）；无分数条目（如刚编译生成的卡片）保留。答案来源列表与实际证据一致 | 自动 |
| B02 | 提示词新增「主体完全无关时直接拒答」：一句话说明后结束，禁止罗列其他主体的数值代替拒答 | 自动 |

### 安全与权限边界

| 项 | 变更 | 生效条件 |
| --- | --- | --- |
| C01 | TOTP 种子不再明文存储，改用与模型凭据相同的 AES-256-GCM 信封；读取端兼容历史明文；解密失败视为"无可用密钥"，用户可重新绑定而不会被密钥轮换永久锁死 | 自动 |
| C02 | `PATCH /admin/users/:id` 支持 `mfaEnabled`，关闭时一并清除种子与重放计数。丢失验证器的用户此前无法通过任何管理接口恢复 | 自动 |
| C03 | 确认密码路径始终可用于自助解绑。登录会推进 TOTP 计数器，账号此前可能卡在启用态 | 自动 |
| C04 | 文档 ACL 读写入口的越权响应统一为 404。此前 `/file` 返 404 而 `/acl` 返 403，等于确认了该 id 属于他人 | 自动 |
| C05 | 权限中止提示由英文内部错误改为中文说明；中止语义（权限撤销最高优先级）保持不变 | 自动 |

### 前端

| 项 | 变更 | 生效条件 |
| --- | --- | --- |
| D01 | 标签页回到前台时立即轮询一次运行状态。此前后台固定 8 秒节流，用户切回后已完成的回答仍要空等一个周期，表现像卡死 | 自动 |

## 保留边界（不在本版本声称的范围）

- `verifying` 阶段长尾未修复：个别问答服务端该阶段持续数分钟。P50 已改善，长尾仍在，建议后续为该阶段设置超时与降级。
- 引用过滤采用相对阈值，未针对特定供应商分制调参；provider 侧分数分布变化可能需要重新校准。
- 压缩包大小上限（500 文件 / 100MB / 单文件 50MB）沿用既有配置，本版本只验证了过滤与展开行为，未测上限边界。
- 未覆盖：200MB 单文件上传、并发压测规模、移动端布局、行业库授权完整流程、管理后台多数面板的逐项操作。
- 本版本所有验证均在本地测试栈完成，未在生产环境执行任何操作。
