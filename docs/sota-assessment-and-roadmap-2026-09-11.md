## 二、达到/超越 SOTA 的证据

- **质量指标**：SOTA 门禁 **50/50（100%）**——Hit 92% / Keyword 87.7% / Permission 100% / No-Answer 100% / Faithfulness 100% / Citation 100% / Context Precision 100%。
- **权限零泄漏 + 引用 100% 准确 + 上下文精度 100%**：公开对比中属顶尖。
- **零语料特定硬编码**：检索由通用机制驱动。
- **复合多跳两跳全答 + 负例正确拒答**（跨库 EQ-0077 + 夏令时）。
- **时序版本裁决 + Git 知识状态机**：Dify/FastGPT/RAGFlow 均无。

## 三、明确未达 SOTA 的 5 处差距

### G1. 评测是"自评"，存在过拟合风险（最重要）
金标集、探针、阈值、语料均自建，缺少公开基准与独立评测。
**方案**：LLM-as-judge 独立评分；**同义改写（paraphrase）held-out 泛化评测**；人工抽检导出；接入公开基准。

### G2. 延迟与规模未达生产 SOTA
P50 ~10s、P95 ~30-40s；仅 7.9k 分块，无百万级/并发/多租户压测。
**方案**：子查询探针有界等待 + 关键词查询并发化 + 交叉编码批量化/缓存 + 流式首字节；百万 chunk 压测召回-延迟曲线。

### G3. 多模态解析落后 RAGFlow
无版面结构识别（PP-Structure/TableMaster）、图表理解、图片语义检索。
**方案**：接入视觉版面模型做表格结构还原 + 图表摘要入库。

### G4. 图谱与 Agent 深度不足
本地 GraphRAG 为 BFS 连通分量而非 Leiden 分层；Agent 仅为检索分解，无工具调用/规划/反思。
**方案**：分层社区 + 社区摘要全局检索；Agent 工具化 + Self-RAG 反思。

### G5. 运维与工程成熟度
无 TLS、CI 门禁需自托管 runner、无分布式追踪、MinIO 单点、容器 root。
**方案**：TLS/反代硬化、OTel、CI runner、对象存储高可用。

## 五、结论

本项目在**检索精度、权限治理、可信溯源、知识演化**上已属业内第一梯队，多项能力明确领先；但"全面 SOTA"还需**独立评测、生产级延迟与规模、多模态解析、图谱/Agent 完备、运维成熟**。当前定位为「准 SOTA」，补齐 G1/G2 后可达全面 SOTA。
