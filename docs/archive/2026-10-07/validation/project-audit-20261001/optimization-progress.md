# 后续优化实施与验证

本记录接续首轮审计及授权变化故障修复。用户已授权落实优化；本轮修改在开发区和
本机隔离测试环境验证，没有发布生产。整体 SOTA 路线仍未全部完成。

## 本轮已实现

1. 主壳只等待 session，不再等待会话列表；会话列表独立异步刷新。
   session/会话请求上限 15 秒，管理数据请求上限 30 秒，超时覆盖响应体读取。
   新加载和组件卸载会取消前一轮请求，令牌及请求序号继续阻止迟到结果覆盖新会话。
2. 登录页按需加载 ChatScreen；MFA 二维码组件也按需加载，不增加普通登录的二维码代码。
3. session 的 503/网络故障不再触发昂贵的管理全量回退，也不再清除有效登录凭证；
   401 清除无效凭证，403 保留强制改密判断。只有旧后端的 404/405 回退管理接口。
4. 校准配置改为单条、有文件变更失效的缓存。重复评分复用读取与解析结果；删除、
   原子替换、文件修改会重新读取或返回未知置信度。继续校验模型、路由、修订和验证集；
   修复缺失/字符串/非整数样本量可能绕过校验的问题。
5. Source 规划在同一次调用中复用已授权计划，减少重复权限与知识库读取；每个新请求
   仍重新获取权限。新鲜度检查中的应用数据库库存与 GBrain 状态读取改为并行，
   两路都成功后才判定新鲜度；未移除现有权限或版本屏障。
6. 修复 MFA 页面将完整 otpauth URI（含 TOTP 密钥）发送第三方二维码服务的问题。
   改用本地 qrcode 1.5.4 绘制 canvas，失败时可继续使用已有手动密钥绑定。
   原始第三方请求曾使用过的账户应评估重新绑定 MFA；本次未擅自重置任何账户。
   实现依据：[node-qrcode 官方说明](https://github.com/soldair/node-qrcode)。

## 已验证

- `pnpm test`：6 个任务成功；API 116 个套件、899 项通过，词法集成原有 5 项跳过；
  Web 50 项通过。后续登录失败处理改动又完成 Web 构建、50 项单测和浏览器验证。
- 独立 `gbrain_core_opt_test` 数据库的入库替换、版本发布/回滚、图谱投影和 RLS
  矩阵通过；真实撤权仍阻止旧版本请求继续输出。
- 校准新增测试验证 100 次评分只读取一次文件、原子替换立即生效、删除后不再返回
  缓存概率，以及非法样本数拒绝。Source 规划新增测试验证一次请求只查一次权限，
  下一次请求能观察到撤权。
- 浏览器夹具令会话列表和管理数据都延迟 3000ms，两次主壳输入框观测分别为
  1098ms、最终版本 911ms，
  两个慢接口都尚未完成。另验证停止保留部分答案、迟到历史隔离、反馈 ID 和错误、
  同数量知识库授权变更及移动端无溢出。此数据为本地单次冷加载观测，不是 LCP/P95。
- MFA 画布二维码由 OpenCV 解码后与测试 provisioning URI 完全一致；浏览器没有
  第三方二维码请求，也没有在请求 URL 中发送密钥。未登录页面未下载聊天渲染代码。
- 浏览器模拟 session 503 保留凭证、401 清除凭证；两者均未请求管理全量接口。
- 新改的 bootstrap hook 和本地二维码组件专项 ESLint 通过；项目整体原有 lint 债务
  尚未清零，没有通过关闭规则掩盖问题。

## 仍需继续

此前 80.397 秒真实问答的阶段记录：GBrain 检索 29.801 秒、生成 22.400 秒、证据
充分性判断 8.365 秒、查询改写 8.012 秒、新鲜度 4.749 秒、Source 规划 2.447 秒。
阶段可能有重叠，不能简单求和当作总时间。本轮减少重复准备与加载开销，尚未用
足够同语料、同权限、同模型的配对样本证明端到端改善，不能宣称解决了 80 秒等待。

更新到测试环境后的同类真实问题仍耗时 **82.112 秒**，授权版本稳定，生成、引用验证
和保存成功。该次新鲜度检查为 3.228 秒，但 Source 规划为 3.145 秒；检索 29.308 秒、
生成 21.925 秒、引用验证 6.028 秒，表明本轮准备阶段优化尚未解决主要等待。
两次调用的运行负载、缓存和监测采样间隔不完全相同，不能把差值解释为因果改善。
原始阶段摘要见 `optimization-live-query.json`。测试 API 和 Web 已恢复由 systemd 管理，
均运行正常且重启计数为 0；生产环境未操作。

后续重点是证据驱动的检索预算、长会话分页与诊断按需读取、完整任务契约、入库
阶段可视化、真实连接器身份/撤权/删除回归、真实 Web Vitals 与冻结语料质量门禁。
百万块及十实例容量试验仍需要非生产测试数据盘/服务器；本机根盘空间不足。
