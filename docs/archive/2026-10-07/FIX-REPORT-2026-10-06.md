## 用户决定与边界

- 立即停用 URL 中的 AppSecret、MFA 票据，客户端使用 Header 或请求体。
- 区分迁移角色与 API 运行角色；运行角色保留 NOBYPASSRLS，迁移角色承担迁移及受控基础服务操作。
- 本轮不生成真实检索概率校准样本，不伪造校准概率；无校准数据的自适应路径明确降级并补覆盖。
- 默认发布执行常规静态、单元、功能检查；只有 `--gate=full`、`--gate-profile=full` 或显式 `GATE_STRICT=1` 才要求严格在线质量门禁。
- 本轮不执行付费严格评测，不迁移浏览器 Bearer 存储至 HttpOnly Cookie。后者为潜在纵深防御建议，未发现报告描述的可达 XSS。
