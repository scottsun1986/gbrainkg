# GBrainKG v56.0 — 核心业务流程正确性、恢复与测量大版本

发布日期：2026-10-09。基线 `8b87764`（v55.0.3），评估依据 [核心业务流程对标评估与优化建议](核心业务流程对标评估与优化建议-2026-10-09.md)，实施记录见 [核心业务流程优化实施记录](核心业务流程优化实施记录-2026-10-09.md)。

## 为什么发这个版本

评估结论是：项目已具备完整企业知识库业务闭环，主要矛盾从“缺少检索算法”转为“现有算法是否产生可重复的净收益，以及权限、版本、来源、任务恢复能否贯穿所有分支”。本版本不改技术主干，按 F01–F10 逐项修复业务正确性与可恢复性缺口，并补齐测量基线；没有新增向量库、图数据库或平行检索服务。

## 保留边界（不在本版本声称的范围）

- F05 同类型同名实体仍共享身份键，完整消歧需审计驱动与人工复核。
- F07 配对消融需要真实模型凭据与固定语料，本版本只提供测量工具与预算入口，不声明通道净收益。
- F09 50k 为本地实测上限，未测 10 万块、生产硬件与多实例并发发布。
- F01 回收依赖下一次同步被触发（自愈），未新增独立巡检调度。
- 带凭据的 live gate 未运行的层保持“未测”语义。
