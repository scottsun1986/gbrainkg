# v52.0 — 知识问答准确性、多源透明与排版一致性大版本

本版本聚焦**知识问答链路**（提示词 / 召回 / 引用 / 排版）与**前端弹窗交互**，按项目原则"**不裁决、多源并列、不杜撰**"修复了一批真实问题，并完成测试环境验收。

## 主要变更

### 1. 回答提示词：中文为主、决策流程化（`7380fb2`）
- 答案提示词由中英平行的规则清单重构为**中文唯一权威**的「决策流程 + 输出规范」；英文降为**次要附加块**（语言强制 + 契约摘要），从根上消除中英漂移。
- 决策流程按覆盖情况分流：**同属性多源差异并列 → 多源一致合并 → 单源直答 → 无源给部分事实+缺口 → 问项歧义才附其他理解**。
- 新增规则：**完整呈现匹配原文**（给出结论后带上与问题直接匹配的原文关键表述）、**否定与缺失问法**、**时间相对问法**。

### 2. 多源与引用透明
- **同属性多源差异必须并列**（`ebd7be9`）：两份制度对同一属性取值不同时全部并列、逐条标注来源与适用范围，**不选其一、不判效力、不合并**，由用户按适用情形决定。
- **完全相同内容的文档都引用**（`c12abbb`）：KB 中存在逐字节重复文档（同一 `Document.contentHash`）时，被引文档的全部相同副本一并进入参考列表（新角标、权限校验），参考链接数不再取决于"哪份副本恰好排在前"。

### 3. 召回完整性（`a716bf9`、`e3ceea4`）
- **RAPTOR 摘要 → 源切片回补**：命中派生摘要时按 `sourceChunkIds` 取回**原始切片**（授权+已发布+有界），避免有损摘要成为唯一证据导致漏项。
- **枚举兄弟补拉**：对枚举型切片补拉紧邻下一兄弟切片，小切片不再被孤立丢弃。
- **摘要提取完整性**：`extractiveSummary` 识别 `**第X条**` 等加粗条款标题；标题上限（默认 40）与输出上限（默认 1800）可配。

### 4. 回答排版与加粗一致性（`771c086`、`e3ceea4`）
- 新增确定性 `normalizeAnswerLayout`：块级元素（来源/分节标题、列表、表格、代码、引用）前补空行、拆分粘连标签、清理残句；块与块之间恰好一个空行。
- **加粗只用于独立成行的来源/分节标签**；非标题正文与句内强调一律不加粗（提示词 + 确定性规范化 + 前端渲染三处一致），消除"有的换行、有的不换"。
- **来源标签加粗一致**：模型对同一回答的来源标题有的加粗、有的不加粗（如"来源1"加粗而"来源2"不加粗）。提示词要求同一回答的标签加粗必须一致；`boldSourceLabels` 再把所有未加粗的来源标题统一补为加粗（含跨行括号限定），保证一致。
- 回答更完整：先给结论，再带上与问题直接匹配的原文关键表述。

### 5. 前端弹窗交互（`e709914`）
- 弹窗遮罩由 `onClick` 改为 **`onMouseDown` + `e.target === e.currentTarget`**：在输入框内拖选文字（含**从右向左**）不再误关弹窗；直接点击遮罩空白处仍正常关闭。覆盖共享 `Modal`、文档预览、命令面板、帮助浮层、侧边导航、会话抽屉共 6 处遮罩。

### 6. 回答范围与证据完整性（`121380a`、`b024330`）
- 保留回答范围与有证据支持的框架；简明回答以完整范围证据为依据，避免范围泛化与遗漏。
