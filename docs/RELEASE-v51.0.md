# v51.0 — 检索质量、GraphRAG 与运行可靠性大版本

本版本整合 2026-10-07 SOTA 评估后的代码优化、回归修复和测试环境验收。仅提交 GitHub 源码与说明，不包含生产部署。

## 优化点

- **检索与回答**：拆分 Chat 编排、证据充分性判定、确定性扫描和回答提示构造；强化通用混合检索融合、重排分数契约、引用组装及拒答证据门槛。
- **GraphRAG 与编译**：增量图谱投影、来源/版本范围校验、全量输入覆盖与主题导航；社区检索采用稠密与词法协同，并保护产物依赖及发布版本一致性。
- **权限与缓存**：收紧证据输出授权和依赖范围；增加权限缓存失效广播、Redis重连处理、限流和模型准入保护。
- **可靠性与规模**：修复大批量Source同步分页导致旧页丢失；补充服务任务丢失恢复、社区产物授权/配额及大规模依赖回归验证。
- **评估工具**：增加校准、配对检索、ANN召回、官方主题扩展和只读SOTA20评测能力，修正评测映射中摘要被误判为原始文档的情况。

## 验证

- `pnpm run test:all`：API 162 suites、1,379 tests通过（5 skipped）；parser 54 tests + 4 subtests通过；adapter 17/17通过。
- SOTA20 当前测试配置：20/20本地数据集、全部本地查询评测成功，退出码0。每集语料文件为100条记录；宏平均 nDCG@10 0.826524、MRR@10 0.869546、Recall@10 0.847904。此结果不是上游全量语料榜单对比。
- 专项证据、限制和待完成质量门槛见 `docs/SOTA-OPTIMIZATION-TEST-RESULTS-2026-10-07.md` 与 `docs/SOTA-FIX-TODO-2026-10-07.md`。

多跳独立事实裁决、同条件配对收益、部署版本概率校准、HNSW-only召回门槛、真实模型综合质量、社区采样/全量成本对照、生产并发、多进程Redis分区、浏览器会话复用以及上游全语料统计对照仍需后续验证。不得据此发布生产。
