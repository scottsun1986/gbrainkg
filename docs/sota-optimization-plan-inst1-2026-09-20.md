## 已修复（本轮）

1. **平台重排未生效**（根因）：把全部候选（实测 180 条 × 3000 字）一次性发给 `/rerank`，且超时硬编码 15s，异常被吞 → 现象是"配了没用"。
   修复：`RERANK_MAX_DOCS`（默认 60）截断 + `RERANK_TIMEOUT_MS`（默认 60000）+ 跳过原因显式告警。实测 trace：`rerank success / platformApplied=true / 489ms`。
2. **三条队列被暂停**：`ingestion-queue`、`enrichment-queue`、`dirty-compiler-queue` → 全部恢复；僵尸作业清理 3,919（compiler）+500（ingestion）。

## 优化项（按预期收益排序，逐项 A/B）

## A/B 协议（固定不变）

1. 语料：SciFact（5,183 篇）与 NFCorpus（去重到 3,633 篇）固定不变；
2. query 集：官方 `queries.jsonl` 的 test 划分（SciFact 300、NFCorpus 323）固定不变；
3. 每次只改一个变量，其余配置冻结；跑完即用 `standard_ir_eval.py` + 官方 qrels 打分；
4. 产出：`run_*.jsonl` + 指标写入本文件，形成版本矩阵；
5. 记录 p50/p95 延迟（同一批 query 的端到端耗时），质量提升不能以不可接受的延迟为代价。

## 执行顺序

1. 等 SciFact+重排 / NFCorpus(混合) 两个 run 结束 → 回填上表
2. 优化项 1（重排覆盖面）→ A/B
3. 优化项 2、3（短文档与词法预算）→ A/B
4. 补 NFCorpus 干净复测（去重后）与中文基准、多跳集
5. 全部完成后给出更新版 SOTA 门禁判定
