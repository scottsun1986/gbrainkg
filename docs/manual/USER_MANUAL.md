## 第二章：知识库三级隔离与生命周期管理

平台构建了业界领先的 **三级多租户知识库隔离架构**，确保数据在物理与逻辑层面的绝对安全性：

![知识库主工作台](screenshots/deep_test/01_logged_in_dashboard.png)

### 2.1 三级知识库核心定义
1. **个人知识库 (Personal KB)**：
   - **可见性**：严格仅创建者本人可见，不支持跨账号共享与派生授权。
   - **应用场景**：个人调研笔记、敏感草稿、待整理原始素材。
2. **组织知识库 (Organization KB)**：
   - **可见性**：依据企业行政组织树（部门/中心/小组）自动继承，部门成员开箱即用。
   - **应用场景**：部门制度规范、业务 SOP、技术文档、项目协作档案。
3. **行业标准库 (Industry KB)**：
   - **可见性**：企业级公共权威库，由超级管理员统一创建，通过 ACL 授权给指定人员、角色或部门节点。
   - **应用场景**：国家法律法规、行业合规标准、集团红头文件。

---

### 2.2 新建个人知识库实操

![新建知识库弹窗](screenshots/deep_test/02_new_personal_kb_modal.png)

#### 操作步骤：
1. 点击左侧主导航栏的 **「知识库」** 图标（或按下快捷键 `⌘2`）。
2. 在左侧面板上方点击 **「+ 新建个人库」** 按钮，弹出新建弹窗。
3. **输入名称**：输入知识库标题（如 `企业合规研究专题库`）。
   > **边界约束**：名称不能为空，名称为空时「创建」按钮将保持置灰禁用状态。
4. **输入描述**：填写知识库的业务定位与说明（如 `用于跟踪数据出境与隐私合规相关文献`）。
5. 点击 **「创建」** 按钮，系统完成数据库写入并在左侧列表实时高亮新卡片。

![新建知识库成功展示](screenshots/deep_test/03_kb_created.png)

---

### 2.3 知识库多维过滤与切换
在知识库列表顶部，提供了即时分类筛选 Tab：
- **全部**：聚合展示当前用户可见的所有三级知识库。
- **个人**：仅过滤出属于当前用户的私有知识库。

- **行业**：展示已获得授权的行业标准与公共政策库。

## 第三章：多格式文档入库、版面解析与父子分块

LLMWiki 集成了先进的 **Docling 高保真版面解析引擎** 与 **Parent-Child（父子层级）分块架构**，确保表格、标题层级与长上下文不发生语义丢失。

![文档管理与表格视图](screenshots/deep_test/05_doc_table_updated.png)

### 3.1 异步非阻塞上传与批量并发处理 (Non-blocking Upload)

系统采用**完全异步非阻塞的文档接收与后台处理架构**。在知识库中上传文档后，前端无需停滞等待解析完成，上传按钮与拖拽区域保持完全可用，支持立即连续上传下一个文档或批量多选上传：

![非阻塞并发上传进行中](screenshots/deep_test/40_async_nonblocking_upload.png)

#### 核心交互与进展跟踪机制：
1. **多选与拖拽支持**：支持点击「上传文档」按钮在文件选择器中按住 `Ctrl/⌘` 多选，或直接将多个文件拖入拖拽区域。
2. **零等待非阻塞响应**：选定文件后，系统毫秒级将文件送入后台接入流水线并给出气泡提示，**上传按钮与拖拽区绝不锁定**，随时可继续添加。
3. **动态状态实时轮询**：
   - 刚上传的文档在表格中即时呈现为 **`🟡 解析中`** 或 **`🟡 索引中`** 状态。
   - 前端后台采用低负载自动轮询机制，文档处理完毕后状态自动无缝跃迁至 **`🟢 已发布`**，无需用户手动按 F5 刷新页面。

![后台自动解析索引完成](screenshots/deep_test/41_async_upload_completed.png)

---

### 3.2 支持的文件格式与自动版面还原
- **Markdown / 纯文本**：`.md`, `.txt`（即时解析分块）
- **富文本办公文档**：Word (`.docx`, `.doc`), Excel (`.xlsx`), PPT (`.pptx`)
- **固定版式文件**：PDF (`.pdf`, 支持单双栏、扫描件 OCR 与跨页表格)
- **结构化数据**：`.csv`, `.html`

---

### 3.3 手动录入结构化 Markdown 文本

![添加文本知识弹窗](screenshots/deep_test/04_add_text_modal.png)

#### 操作步骤：
1. 在选中的知识库主界面，点击右上角操作栏的 **「+ 添加文本」** 按钮。
2. **输入标题**：输入文档名称（如 `企业数据出境安全评估操作指南`）。
3. **录入正文**：在文本框中输入标准 Markdown 内容（支持多级标题、有序/无序列表、代码块与表格）。
4. 点击 **「保存并索引」** 按钮。
5. 系统自动启动高可用多级后台处理流水线：
   - **PDF 文档**：第一级采用 `pypdf` 高速结构化解析（50ms 提取原生排版与分页），并自动过滤字体编码中的 `\u0000` 空字符；对扫描件无缝降级至 `Docling Layout OCR` 模型。
   - **Word 文档**：第一级采用 `python-docx` 提取标题层级与表格，并对老旧 `.doc` 启用 `antiword` 引擎转换。
   - **Excel 表格**：第一级采用 `openpyxl` 转换为标准 Markdown 表格。
   - **分块与向量化**：标准 Markdown -> 父子分块 (1800/200) -> bge-m3 向量化 -> Compiled Truth 知识库实时编译与在线检索。

![PDF等多格式文档全量成功解析发布](screenshots/deep_test/42_pdf_all_published.png)

### 3.4 通用文档前端预览与知识切片洞察 (Universal Document Viewer)

系统搭载了业界主流的前端高保真渲染套件（集成 `docx-preview` 原生 Word 渲染器、`marked` Markdown 排版引擎、`xlsx` SheetJS 多工作表表格解析器与浏览器原生 PDF 引擎），彻底告别外部复杂文档服务器依赖，支持毫秒级无缝预览：

![PDF深度结构化解析视图](screenshots/deep_test/44_pdf_parsed_markdown.png)

#### 四维多模态预览选项卡：
1. **📄 原文档排版 (Raw Render)**：
   - **Word (`.docx`, `.doc`)**：纯前端 DOM 排版还原（支持段落、字体、内嵌表格与页边距）。
   - **PDF (`.pdf`)**：浏览器原生矢量渲染，自带缩放、页面定位与搜索。
   - **Excel (`.xlsx`, `.csv`)**：交互式多 Sheet 切换器，提供带斑马纹的响应式表格数据透视。
   - **Markdown / 纯文本**：GitHub 风格美化排版与代码高亮。
2. **🧠 Docling 解析视图 (Parsed View)**：
   - 展现经深度版面分析后提取的规范化 Markdown 结构树，方便对照清洗质量。
   
   ![Docling解析视图](screenshots/deep_test/44_pdf_parsed_markdown.png)

3. **🧩 知识切片与向量 (Chunks Inspector)**：
   - 直观展示文档被拆分成的细粒度检索 Chunk（包含 `#0`, `#1`, `#2` 序号、Token 计数、字符区间），支持一键复制单分块。
   
   ![知识分块与向量列表](screenshots/deep_test/45_pdf_chunks_inspector.png)

4. **⚙️ 元数据属性 (Metadata)**：
   - 审查文档的唯一 UUID、所属库 ID、存储后端归档状态、发布生命周期与时间戳。

#### 操作快捷键与工具栏：
- **📥 下载原件**：一键导出本地备份。
- **📋 复制全文**：复制经过规范化提取的 Markdown 全文字符。
- **⛶ 全屏沉浸式阅读**：一键切换至 98% 视窗全屏模式。
- **Esc 键 / ×**：随时无阻退出。

### 3.5 库内知识多维搜索、状态过滤与海量分页

为应对企业级海量知识文档资产（成千上万篇规章、技术规范与数据表），知识库文档管理区提供了强大的实时检索、多条件过滤与高效分页组件：

![知识库文档多维搜索与分页控制](screenshots/deep_test/33_kb_doc_pagination.png)

#### 核心功能与操作指南：
1. **🔍 实时文档检索**：在搜索栏中输入文档名称、关键字或存储相对路径，表格将毫秒级联动过滤。
2. **多状态精确筛选**：
   - `全部状态`：查看当前库内所有文档。

## 第四章：智能对话问答与 Compiled Truth 可信证据链

不同于传统的黑盒 RAG 简单向量拼接，LLMWiki 采用 **编译式知识检索 (Compiled-then-Query)** 架构，为金融与政府级应用提供不可伪造的真实性保障。

![智能问答与证据链展示](screenshots/deep_test/08_chat_stream_completed.png)

### 4.1 检索范围灵活控制 (Scope Picker)

![检索范围选择器](screenshots/deep_test/07_scope_picker_opened.png)

#### 操作步骤：
1. 进入 **「对话」** 模块（或按快捷键 `⌘1`）。
2. 在输入框底部的胶囊工具栏中，点击 **「范围 · 我可见的全部 ⌘K」**。
3. 在弹出的多选浮层中：
   - 勾选 **「全选」**：跨所有可见库进行全局智能检索。
   - 或单独勾选指定库（如仅勾选 `合规部知识库` 和 `行业标准库`）。
4. 选项即时生效，输入框下方的状态指示灯将更新为已选库数量。

---

### 4.2 发起流式提问与交互体验
1. 在输入框中输入业务问题（例如：`请说明数据出境安全评估的申报条件与核心材料清单？`）。
2. 按下 `Enter` 发送（如需换行请按 `Shift + Enter`）。
3. **SSE 流式生成**：大语言模型以打字机动效逐字输出结构化解答。
4. **数字溯源引用角标**：在正文中出现的每一处结论均自动标注来源角标（如 `[1]`、`[2]`）。
5. **精准证据链展开**：
   - 点击消息底部的 **「大脑整理与查询」** 折叠面板。
   - 即可清晰查看：**权限视图边界判定 -> 主题页检索 -> Compiled Truth 结论生成 -> 原始文档切片对齐** 的完整四级过程。

---

### 4.3 答案质量反馈机制
在每条 AI 回答卡片的底部右侧：
- 点击 **「👍 有用」**：标记该条回答为高质量标准答案，并记录至审计反馈库。
- 点击 **「📋 复制」**：一键将 Markdown 格式完整答案复制到系统剪贴板。
- 点击 **「🔄 重写」**：携带上下文重新触发推理生成。

## 第六章：管理控制台、组织架构树与模型网关配置

超级管理员专属的系统级中枢，涵盖人员、组织树、角色权限、AI 模型网关以及全流程合规审计。

### 6.1 人员管理：组织树联动筛选、多维检索与严格权限收敛

人员管理模块支持**左侧层级组织架构树 + 右侧多维人员表格**的联动交互布局，同时在底层实施严格的组织管理员数据与操作安全边界：

![人员管理与组织树穿透检索](screenshots/deep_test/30_admin_users_org_tree.png)

#### 1. 组织架构树穿透筛选 (Hierarchical Descendant Filtering)
- **全部组织根项**：展示系统内全部用户总数；点击可一键重置组织筛选条件。
- **层级穿透检索**：点击左侧组织树的任意节点（如 `研发中心`），系统自动计算该节点**及其所有下属子部门（如 `开发组`、`测试组`）**的并集，即时筛选出属于本层及以下的所有人员，并在右侧上方呈现黄色提示条：`📁 当前组织筛选：/group/rd 及所有下属部门（共匹配 X 人）`。
- **一键展开/折叠**：支持右上角一键展开或收起整棵组织架构树。

![组织树穿透筛选效果](screenshots/deep_test/31_admin_users_org_filtered.png)

#### 2. 组织管理员权限边界严格收敛 (Org Admin Boundary)
根据企业安全合规基线规范：
- **可看与可管分离**：组织管理员可以查阅系统组织目录中的所有人员（确保跨部门协作与通讯录完整性），但**只能管理属于自己这一层组织及以下组织的成员**。
- **UI 操作防护**：
  - 对属于管辖范围的人员：状态标记为 `可管理`（绿色徽章），提供正常「编辑」与「停用」操作按钮。
  - 对超出管辖范围的人员（如上级集团总部、同级其他部门、系统管理员）：状态明确标记为 `只读查看`（灰白徽章），「编辑」与「停用」按钮被严格禁用（带不可点击禁止图标与悬停提示），杜绝越权误操作。
- **后端双重拦截**：API 层在 `canManageUser` 和用户更新/停用接口中进行强鉴权拦截，即便通过脚本发起请求亦会被拒。

![组织管理员权限边界实测](screenshots/deep_test/35_org_admin_boundary.png)

#### 3. 多维搜索与分页控制
- **综合搜索栏**：实时匹配姓名、用户名（账号）、邮箱、所属组织全路径或角色。
- **角色/状态/权限范围下拉**：支持按 `全部角色`、`启用/停用`、`可管理/只读查看` 复合过滤。
- **分页导航**：支持 `10` / `20` / `50` 条每页容量选择与页码快速跳转。

### 6.3 AI 模型网关与连通性自检

#### 平台三层模型架构：
1. **大语言模型 (LLM · 生成)**：
