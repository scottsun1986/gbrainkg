## 2. 30 大国际权威基准深度解析与格式对齐

### 第一类：开放域事实与语义精准检索 (4项)

1. **MS MARCO** *(Microsoft / TREC)*
   - **挑战场景**：100万+ 真实搜索引擎提问，匹配 880 万候选网页段落。
   - **重点考核**：大库环境下的候选重排与首位排位率（MRR@10、nDCG@10）。
2. **Natural Questions (NQ)** *(Google Research)*
   - **挑战场景**：来自 Google Search 真实用户口语化、倒装句与长尾提问。
   - **重点考核**：真实长尾语义召回，杜绝因字面措辞差异导致的语义漏召回。
3. **BEIR Benchmark** *(UKP Lab, NeurIPS 2021)*
   - **挑战场景**：涵盖 9 大任务、18 个异构领域的多语料集合。
   - **重点考核**：零样本通用泛化检索能力，严禁针对特定场景在代码中做专用同义词或正则硬编码。
4. **SciFact** *(Allen AI, EMNLP 2020)*
   - **挑战场景**：高难度专业科学与生物医药文献事实核查与证据检索。
   - **重点考核**：高壁垒专业学术术语、多重否定句式与学术假设证据判定。

---

### 第二类：多跳推理与图谱链式合成 (4项)

5. **HotpotQA** *(CMU / Stanford)*
   - **挑战场景**：包含 10 个混淆段落的经典 2-hop 问答，明确标注金标准证据集（Supporting Facts）。
   - **重点考核**：双跳跃证据链完整协同召回（Full Evidence）与消除伪单跳干扰。
6. **2WikiMultiHopQA** *(HKU)*
   - **挑战场景**：基于知识图谱的关系路径多跳问答，涵盖组合关系与推理桥接。
   - **重点考核**：跨文档实体链接、隐式从属关系穿透与防噪音淹没。
7. **MuSiQue** *(Allen AI)*
   - **挑战场景**：2~4 步高难度依赖推理问答，严格去除了单跳捷径（Shortcut Exploitation）。
   - **重点考核**：长链深度依赖推理，只有全部跳跃节点全召回方能生成正确答案。
8. **Bamboogle** *(2022)*
   - **挑战场景**：专门针对 Google 搜索引擎优化设计的防单段落作弊两跳问答。
   - **重点考核**：杜绝搜索引擎单一摘要作弊，必须依赖真正的两文档知识拼装。

---

### 第三类：复杂表格、财报穿透与数值计算 (6项)

9. **TAT-QA** *(ACL 2021)*
   - **挑战场景**：真实上市公司财报混合文档，表格包含纵向/横向合并单元格。
   - **重点考核**：合并单元格下属行父级属性穿透填充率、行键值语义绑定。
10. **FinQA** *(EMNLP 2021)*
    - **挑战场景**：深度财报层级结构表，需执行多步骤算术推导（营收比率、增长率、毛利率）。
    - **重点考核**：财务表格数字精度保留、跨行跨列复合推导证据链完备度。
11. **MultiHiertt** *(ACL 2022)*
    - **挑战场景**：跨多页、多层级嵌套财报表格（Multi-page Hierarchical Tables）。
    - **重点考核**：跨页断开表格的表头顺延继承（Header Propagation）、多层级子目录对齐。
12. **FinanceBench** *(Patronus AI 2023)*
    - **挑战场景**：10,231 道基于美国 SEC 官方 10-K、10-Q、8-K 年报季报真实问答。
    - **重点考核**：包含严格会计准则、资产负债表与附注之间的数据对账与公式印证。
13. **WikiTableQuestions (WTQ)** *(Stanford, ACL 2015)*
    - **挑战场景**：半结构化复杂表格上的复合运算（Max/Min、Count-If、特殊符号）。
    - **重点考核**：管道符 `|` 安全转义、复合条件过滤与聚合统计证据。
14. **TabFact** *(EMNLP 2019)*
    - **挑战场景**：1.6 万张复杂维基表格上的事实核验（True/False 裁决）。
    - **重点考核**：表格每一行独立事实陈述的置信度判定。

### 第四类：法律公文、商业合同与层级规范 (3项)

15. **CUAD (Contract Understanding Atticus Dataset)** *(NeurIPS 2021)*
    - **挑战场景**：510 份商业合同，涉及 41 类高风险法律条款（赔偿责任上限、知识产权归属、除外条款）。
    - **重点考核**：跨条文交叉依赖（“除第4条另有约定外，本条赔偿上限为...”）的上下文保全。
16. **LegalBench** *(NeurIPS 2023)*
    - **挑战场景**：涵盖 162 项法律实务推理任务（法规适用、法定权利、判例比对）。
    - **重点考核**：法定规则适用逻辑、法律术语严格定义判定。
17. **QASPER** *(Allen AI)*
    - **挑战场景**：结构化复杂学术报告与公文（包含章节、段落、浮动表格、伪标题）。
    - **重点考核**：中文大纲与加粗字号伪标题的 Markdown 大纲层级（`#`、`##`、`###`）保真度。

### 第五类：多模态视觉、PPT空间流与复杂版面 (8项)

18. **SlideVQA** *(CVPR 2023)*
    - **挑战场景**：多幻灯片演示文稿（PPTX），元素由多个文本框、柱状图、配图组成。
    - **重点考核**：二维空间拓扑阅读顺序（Top-to-Bottom, Left-to-Right）与演讲备注完整提取。
19. **OmniDocBench** *(2024)*
    - **挑战场景**：涵盖多栏排版、密集公式、手写签名、复杂表格的综合版面评测。
    - **重点考核**：单栏/多栏自适应检测、密集表格深度引擎（Docling）自适应路由准确率。
20. **DocVQA** *(CVPR 2021)*
    - **挑战场景**：扫描文档、票据、报表中的视觉图文问答。
    - **重点考核**：版面视觉对齐、文字与边框的物理空间相对关系识别。
21. **InfographicVQA** *(WACV 2022)*
    - **挑战场景**：信息图表（Infographics）复杂非线性视觉流与图文融合。
    - **重点考核**：非线性阅读顺序还原、关键节点属性提取。
22. **ChartQA** *(ACL 2022)*
    - **挑战场景**：柱状图、折线图、双轴对比图表。
    - **重点考核**：坐标轴数值提取、趋势判别与视觉数据逆向还原。
23. **TextVQA** *(CVPR)*
    - **挑战场景**：拍照失真、光照不均、倾斜扭曲文档图像 OCR。
    - **重点考核**：高噪声图片文本提取鲁棒性、缺字漏字容错率。
24. **TAT-DQA** *(ACL 2022)*
    - **挑战场景**：图文与表格混合排版，包含页面正文叙述、中间插入表格与底部特别脚注说明。
    - **重点考核**：表格与正文相互印证、脚注例外说明（Callout）不丢失。
25. **DUDE (Document Understanding Dataset and Evaluation)** *(ICCV 2023)*
    - **挑战场景**：包含 100+ 页的跨行业海量异构工业文档（合同、技术规范书、报表、单据）。
    - **重点考核**：超大多页工业文档跨页特征定位。

### 第六类：超长上下文与极端大海捞针 (3项)

26. **RULER** *(NVIDIA 2024)*
    - **挑战场景**：长上下文（35k~128k Tokens）多针聚合（Multi-Needle in a Haystack）。
    - **重点考核**：首部（25%）、中部（58%）、极尾部（97%）离散隐藏多针的协同无损召回。
27. **LongBench** *(Tsinghua / OpenBMB)*
    - **挑战场景**：超长文档（100+ 页、50+ 篇章）跨章节宏观综述与摘要。
    - **重点考核**：RAPTOR 分层 Map-Reduce 两阶段汇聚覆盖率，全书尾部章节零截断覆盖。
28. **BABILong** *(2024)*
    - **挑战场景**：超长上下文中掺入高达 99% 的强干扰背景噪声。
    - **重点考核**：极端信噪比下的关键事实锁定与抗噪检索能力。

### 第七类：时序冲突、版本演进与可信防幻觉 (2项)

29. **RGB Benchmark** *(CAS, EMNLP 2023)*
    - **挑战场景**：RAG 可信度与鲁棒性核心测试，包含负样本未知拒答（Negative Rejection）。
    - **重点考核**：资料库完全不含答案时 100% 严正拒答，严禁编造；有部分已知事实时客观陈述。
30. **CRUD-RAG** *(2024)*
    - **挑战场景**：知识更新与多版本冲突裁决（Create, Read, Update, Delete）。
    - **重点考核**：新旧版本并存时的时序效力裁决（生效日期、废止继承关系优先于历史旧版）。

## 3. 核心评测指标体系与数学口径

针对生产级全链路 RAG 系统，除底层检索物理指标外，**正式引入国际两大权威评测框架 Ragas 与 DeepEval**，建立“检索-证据-生成”三位一体的端到端质量度量：

### 3.1 Ragas 核心指标规范 (Exploding Gradients)
1. **忠实度 (Faithfulness / 幻觉抑制率)**:
   $$\text{Faithfulness} = \frac{|\{c \in \text{Claims}(\text{Answer}) \mid \text{Context} \models c\}|}{|\text{Claims}(\text{Answer})|}$$
   度量回答中的每一项客观断言是否均能由召回上下文直接推导支持，杜绝大模型“无中生有”或脑补未在资料中出现的数值与实体。门禁要求 $\ge 85.0\%$。
2. **答案相关度 (Answer Relevance / 切题度)**:
   度量回答与用户初始提问语义意图的契合度，惩罚答非所问、冗余套话与空洞免责声明。门禁要求 $\ge 80.0\%$。
3. **上下文精准度 (Context Precision@K)**:
   $$\text{Context Precision@K} = \frac{\sum_{k=1}^K (\text{Precision@k} \times v_k)}{\text{Total Relevant Chunks}}$$
   度量真正支持答案的关键事实切片是否排在检索候选的最前列，最大化信噪比。门禁要求 $\ge 85.0\%$。
4. **上下文召回率 (Context Recall)**:
   $$\text{Context Recall} = \frac{|\{f \in \text{GroundTruthFacts} \mid \text{Context} \models f\}|}{|\text{GroundTruthFacts}|}$$
   度量召回上下文是否完整捕获了黄金答案所依赖的全部要素与跨跳依赖。门禁要求 $\ge 85.0\%$。

### 3.2 DeepEval 核心指标规范 (Confident AI)
1. **Groundedness Metric**: 严格事实锚定度量，通过严密 NLI 蕴含逻辑验证避免未经验证的事实外溢。
2. **Completeness / Coverage Metric**: 针对复合问句、跨行多指标、以及“一问多点”场景，度量全部必要维度的覆盖完整率。
3. **RAG Triad Harmonic Score**:
   $$\text{RAG Triad} = \frac{3}{\frac{1}{\text{Faithfulness}} + \frac{1}{\text{Answer Relevance}} + \frac{1}{\text{Context Recall}}}$$
   综合召回率、忠实度与切题度计算全局调和平均数，作为 RAG 系统端到端能力的统一基准分。

### 3.3 系统底层检索与工程指标矩阵

| 类别 | 指标项 | 数学定义 / 判定口径 | 门槛及格线 | GBrainKG 实测 (v2.1) |
| :--- | :--- | :--- | :---: | :---: |

## 4. 系统准入与防退化门禁基线 (Gate Thresholds)

所有进出生产环境的代码、分块逻辑、Prompt 与检索路由，必须在自动化测试中达到以下门禁：
1. **多跳公开基准 (HotpotQA / 2Wiki / MuSiQue)**：Recall@10 必须 $\ge 98.0\%$，Full Evidence 必须 $\ge 85.0\%$，Ragas Faithfulness 必须 $\ge 85.0\%$；
2. **检索响应性能**：6 召回分支必须并发异步执行，端到端 P95 响应时延不得超过 60 ms；
3. **大模型缓存防退化**：严格保持系统规则静态前缀置顶，严禁将动态变量插入前缀破坏 KV-Cache；
4. **表格与多模态**：合并单元格穿透率必须维持 $100.0\%$，特殊符号转义不破坏列；
5. **长文本全景**：RAPTOR Level-1 节点必须通过 Map-Reduce 汇聚，严禁使用单次 12k 截断尾部章节；
