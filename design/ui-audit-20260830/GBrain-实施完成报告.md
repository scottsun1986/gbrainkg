## 各项明细

### P0-1 品牌更名
- 浏览器标题：`企业级 GBrain 知识库`；侧栏字标：`G` 渐变徽标 + `GBrain` + `企业级知识库` 副标
- 登录页改为 GBrain 字标 + 「登录你的企业大脑」；答案署名 `GBrain · 大脑综述`；分享标题同步
- 登录页不再预填账号 `CY`（生产安全要求）

### P0-2 知识图谱（核心，见 10~16/28/29 截图）
- **力导向布局引擎**：自研 `runForceLayout`（O(N²) 电荷斥力 + 弹簧 + 碰撞分离 + 居心力 + alpha 退火，600 次迭代），零新依赖。替代原三列硬编码布局，154 节点标签叠压问题根除
- **交互**：滚轮以光标为中心缩放（0.3x~3.5x）、空白拖拽平移、节点拖拽重排、悬停高亮一度邻居（其余淡出至 18%）、点选详情、双击直达（文档→OnlyOffice 预览 / 知识库→定位知识库页）、Esc 取消
- **类型过滤**：知识库/文档/主题 三个 chip 独立显隐，带实时计数
- **搜索**：命中高亮（琥珀描边）+ 命中数角标 + Enter 跳选 + ⌘F 聚焦
- **局部图谱**：详情面板「展开局部图谱」以选中节点为中心取 2 度子图重排，可一键返回全局
- **显示设置**：斥力、连线距离滑杆 + 标签显示三档（自动/常显/隐藏）
- **视图工具**：缩放百分比控件 + 适应视图 + 重置 + 居中选中；布局完成后按几何键自动 fit（含 rAF 去竞态；ResizeObserver 跟随画布尺寸变化重排）
- **详情面板**：按关系类型分组（包含/提及/共同主题），行可点击跳转，超 8 条折叠；操作按钮（打开文档/进入知识库/展开局部图谱）；空态展示键位速查
- **App 层**：新增 `openGraphDocument/openGraphKb` 桥接，图谱双击文档可复用 App 级 OnlyOffice 预览

### P1-1 命令面板与快捷键（见 17~19 截图）
- **Spotlight 风格 ⌘K/Ctrl+K 面板**：导航（⌘1~⌘4 直达四屏）、动作（新建对话 ⌘N/新建个人库/上传文档）、知识库搜索、最近会话搜索；↑↓ 选择、↵ 执行、ESC 关闭；无权限项自动隐藏（管理入口按 capabilities 过滤）
- **全局快捷键**：⌘K 面板、⌘1~4 切屏、⌘N 新对话、`?` 快捷键速查浮层、Esc 关闭
- **顶栏**：搜索按钮兑现为面板触发器（带 ⌘K 徽标）；通知→真实面板（当前为引导性消息）；帮助→快捷键速查；全部消灭假 toast 按钮
- **跨屏联动**：面板选会话 → 对话页自动打开该会话（`app-open-conversation` 事件）

### P1-2 对话页（见 20~22 截图）
- 会话列表：新增标题搜索框（即时过滤+清除钮）；按 今天/近 7 天/更早 分组（带计数）；当前会话左侧琥珀指示条
- 引用面板：默认折叠为右缘竖向 rail（图标+「引用」+计数徽标），点击展开为抽屉，头部带收起钮——聊天区不再被常驻挤压
- 流式：发送按钮变为红色 ■ 停止按钮（AbortController 真中断）；用户上滚即停止自动滚底，浮现「↓ 回到底部」胶囊（流式中带脉冲点）
- 发送后强制回到底部（保持原有体验）

### P1-3 右键菜单与撤销（见 23 截图）
- 会话项右键菜单（Windows 11 圆角风格）：打开 / 复制标题 / 置顶（占位）/ 重命名（占位）/ 隐藏（可撤销，红色危险项）
- 隐藏会话即时生效（含当前会话清理），底部 toast 提供 5 秒「撤销」按钮恢复
- 菜单自动视口翻转防溢出；Esc/外点关闭
- 注：多选批量操作因后端无批量接口，列入后续（见「遗留」）

### P1-4 知识库/登录（见 24 截图）
- 文档行：显示原始文件名（修复显示存储哈希路径问题），路径改副标+tooltip；新增按扩展名着色的文件类型图标；操作改图标按钮（预览/重试/删除，删除红色、带 aria-label）；行 hover 反馈
- 知识库卡片：空描述显示「暂无描述」占位
- 登录页：移除预填账号、GBrain 字标、布局更新

### P2 底层治理
- **死代码清理**：删除恒真 `const dbData` 及全部 31 处死分支（`系统正在加载…` 占位）
- **Token 化**：新增 `--on-ink / --ink-hover / --on-evidence` 语义 Token，替换全站 30+ 处 `var(--ink);color:#fff` 类硬编码组合（这是暗色模式可行性的前提）
- **暗色模式**（见 26~28 截图）：完整 Token 映射 + 组件级覆盖（图谱画布径向暗渐变、登录页、文件类型图标、zoom 控件、命令面板遮罩），跟随系统 `prefers-color-scheme`
- **响应式**：图谱页 <900px 详情面板转底部、过滤 chips 换行（保留并增强原 media query）
