## 2. 知识图谱 Obsidian 化重做（P0，核心交付）

### 2.1 现状问题（02 / 07 截图逐条对应）

1. **布局模型错误**：`page.tsx:1991-1996` 用固定三列（KB x=160 / 文档 x=520 / 主题 x=880）+ 纵向均分摆放。154 个主题挤成一列 → 右侧形成一条「橙色发丝球墙」，标签全部互相覆盖（截图中肉眼可辨的标签不足 1/5）。
2. **零交互能力**：SVG 无缩放、无平移、无节点拖拽、无双击下钻；`viewBox` 写死 1100×650，不可适配屏幕。
3. **无过滤维度**：3 种节点类型不能独立显隐；搜索仅做文本过滤并直接隐藏其余节点（而不是 Obsidian 式高亮 + 其余淡化）。
4. **选中反馈弱**：右栏详情只有 3 句静态文案 + 最多 12 条关系列表；无「跳转到文档/知识库」入口，无局部图展开。
5. **无边距治理**：`graph-node` 文本 18 字截断仍互相叠压；节点命中区域仅为圆本身（13~22px 半径），误触率高。
6. **性能天花板低**：全量 SVG DOM 渲染，千级节点即卡；现有 4 文档/154 主题/166 关系虽小，但企业级目标必须按万级设计。

### 2.2 目标形态（对标 Obsidian Global Graph）

**布局引擎**：引入 `d3-force`（力争不新增重依赖；如后续节点 >2k 再评估 canvas/WebGL 渲染层，接口不变）。首次进入执行力导向模拟（约 300ms 收敛），支持「重新布局」按钮。

**必备交互（Obsidian 对齐清单）**：

| 能力 | 规范 |
|---|---|
| 缩放/平移 | 滚轮缩放（以光标为中心）、空白处拖拽平移、`⌘/Ctrl+滚轮` 快缩放；左上角悬浮 +/−/适应按钮与百分比 |
| 节点拖拽 | 拖拽单节点后局部再收敛（fx/fy 钉住，松手不钉，与 Obsidian 一致） |
| Hover | 高亮 1 度邻居，其余节点与边淡出至 10% 透明度；邻居标签强制显示、非邻居标签隐藏（解决标签叠压的根本手段） |
| 点选 | 右侧详情面板（见 2.3）；画布内选中节点描边高亮 |
| 双击 | 文档节点 → 打开 OnlyOffice 预览（复用现有 `preview-config` 接口）；知识库节点 → 跳转知识库页并定位 |
| 搜索 | 输入即高亮匹配节点 + 匹配数角标，回车/点击结果居中到节点并选中；其余节点淡化（不隐藏） |
| 类型过滤 | 顶栏 3 个类型 chips（知识库/文档/主题）点击显隐，带数量徽标；隐藏类型的相关边联动隐藏 |
| 局部图谱 | 详情面板「展开局部图谱」：以选中节点为中心的 1~2 度子图重新布局（Obsidian Local Graph 模式），返回按钮回到全图 |
| 显示设置 | 右下角齿轮弹层：斥力、连线距离、节点大小按连接数缩放开关、文字常显开关、箭头开关（Obsidian 同款参数项） |
| 键盘 | `Tab` 在节点间移动、`Enter` 选中、`Esc` 取消选中；节点 `role="button"` + `aria-label` |
| 空态/权限 | 保留现有权限文案；空态给「去上传文档」行动按钮 |

**视觉规范**：
- 画布底色 `--paper`，网格/噪点可选；连线用中性灰 `--line-2`，`related_to` 用主题色而非现在的高饱和橙，宽度 1~3px 按权重。
- 节点配色沿用现三色但降饱和（紫 `#8b5cf6`→`#7c6cd9`，蓝 `#2563eb`→`#4c7fd0`，橙 `#c47a18`→`#c08a3e`），节点半径按连接数 6~24px 分档，选中态白描边 + 外圈光晕。
- 标签 11px、单行省略，仅 hover/选中/搜索命中/低缩放比例时显示（分档 LOD）。
- 图例移入左下角悬浮半透明卡片，不再占底部整行。

### 2.3 详情面板重做（右栏 320px）

- 头部：类型徽标 + 名称 + 连接数；操作行：`打开文档`（文档节点）/ `进入知识库`（KB 节点）/ `展开局部图谱` / `在对话中提问`（带该节点上下文跳转对话页并预填问题）。
- 关联列表：按关系类型分组（包含/提及/共同主题），每行可点击 → 画布居中该节点；超过 12 条折叠 + 「显示全部」。
- 文档节点追加：所属知识库、上传者、更新时间（数据已在 `graph.nodes` 中可扩展返回，不改表结构）。

### 2.4 性能护栏

- 模拟期间 `requestAnimationFrame` tick 渲染；收敛后静止渲染。
- 视口裁剪：仅渲染可视区域内节点/边。
- 目标：1 万节点 / 2 万边下 hover 响应 < 100ms（P2 阶段以 canvas 渲染达成，P0 以 SVG + 裁剪先满足千级）。

## 3. 全局操作范式（Apple / Windows 对标，P1）

当前系统除 `Esc 关闭弹窗` 外没有任何快捷键、命令面板、右键菜单、撤销——这是与 Apple/Windows 体验差距最大的一层。

| 能力 | 设计 | 对标 |
|---|---|---|
| 命令面板 | `⌘K / Ctrl+K` 唤起，聚合：页面跳转、知识库/文档搜索、会话搜索、动作（新建会话、新建个人库、上传文档）。现在 TopBar 搜索按钮只弹 toast（`page.tsx:286`），⌘K 徽标是假的（`page.tsx:710`）——两者统一由命令面板兑现 | macOS Spotlight |
| 快捷键 | `⌘1..4` 切换 对话/知识库/图谱/管理；`⌘N` 新建会话；`⌘F` 聚焦当前页搜索；`?` 呼出快捷键速查浮层；所有 tooltip 附快捷键提示 | macOS / Win11 |
| 右键菜单 | 会话列表项（重命名/置顶/删除）、文档行（预览/下载/删除）、图谱节点（展开局部图/打开/复制名称） | Windows 11 圆角菜单 |
| 危险操作 | 删除文档/知识库：确认弹窗升级为「输入名称确认」（删除 KB 时）；删除会话/文档改为 toast 内 5 秒撤销 | Apple HIG destructive |
| 多选 | 列表支持 `Shift` 连选、`⌘/Ctrl` 点选 + 批量删除/移动 | Windows 资源管理器 |
| 拖放 | 全局 dragover 显示上传遮罩，松手落入选中知识库 | macOS Finder |
| 顶栏三按钮 | 搜索→命令面板；通知→真实未读（解析失败/权限变更）或暂时移除；帮助→快捷键+上手浮层。禁止无功能占位按钮 | — |

| 焦点可见 | 全局 `:focus-visible` 2px 描边，键盘可达 | Win11 Flux/Apple |
| 响应式 | <1024px 侧栏抽屉化、图谱页详情面板改为底部抽屉；当前完全无适配 | — |

## 4. 逐页视觉分析与优化清单

### 4.1 对话页（01 截图）— 中度优化

**问题**：
1. 会话列表存在 10+ 条同名重复会话（「请用一句话说明数据出境安全评估需要关注什么？…」），无搜索、无按日期分组、无 hover 操作 → 噪音极大。
2. 欢迎区文案过载（三行长段落），建议问题 chips 样式弱。
3. 引用面板 `cite-panel` 常驻右侧挤压聊天区；`Truth —` 占位徽标无信息量。
4. 消息操作行（复制/重写/分享/有用）缺少「无用」反馈；重写按钮直接重发旧问题、无 loading 区分。
5. 输入框 `⌘K` 徽标与「范围」chip 功能重复；上传附件 chip 权限不足时仅降透明度、无解释 tooltip。
6. 流式输出期间用户上滚会被强制拉回底部（`page.tsx:484-487` 无条件滚底）。

**优化**：
- 会话列表：顶部搜索框；按 今天/7 天内/更早 分组；hover 显示 `…` 菜单（重命名/置顶/删除+撤销）；当前会话高亮左侧 3px 主题条。
- 欢迎区：主标题一句 + 副标一句；建议问题卡片化（图标 + 两行截断），`⌘K` 打开面板。
- 引用面板改为可折叠抽屉（默认折叠为右缘竖条显示「引用 ×N」），点引用 chip 自动展开；移除 Truth 占位徽标。
- 消息操作：hover 消息浮现（Apple 式），补「无用」按钮，反馈后按钮态持久化；重写期间旧答案置灰。
- 流式期间用户上滚即停止自动滚底，出现「回到底部」悬浮按钮。
- 停止生成按钮（streaming 中发送按钮变 ■ Stop，`AbortController` 已存在，仅补 UI）。

### 4.2 知识库页（03 截图）— 轻度优化

**问题**：
1. 文档表「文档」列显示存储路径 `fb279534-2bed-...-content.md` 而非原始文件名（`loadDocuments` 用 `doc.title`，后端落了 mdPath 类值）——显示层需回退取原始文件名；「大小」恒为 `—`。
2. 行操作「预览 / 删除」为纯文本按钮，视觉重量与主表不匹配。
3. 上传区仅存在于「文档」tab 顶部；健康度/设置 tab 内容未走查（本页 P1 复查）。
4. 知识库卡片 `desc` 为空时高度塌陷不齐。

**优化**：
- 文档名列显示原始文件名 + 类型图标；路径改 tooltip；大小由上传时写入或接口补齐。
- 行操作改图标按钮 + `…` 菜单；删除走统一危险样式。
- 支持整个详情区拖放上传；上传中行内进度条（现有轮询已具备，补 UI 状态机：排队/解析中/已发布/失败 + 失败原因 tooltip）。
- 卡片空 desc 显示占位文案「暂无描述」，固定卡高。

### 4.3 管理后台（04/05 截图）— 中度优化

**问题**：
1. 组织架构页内容仅占左侧 1/3，右侧 2/3 全空；树节点操作（新增下级/编辑/删除）不可发现。
2. 人员表无分页/排序/批量；搜索框与「新增人员」分离在标题行两端，视觉断裂。
3. 表格密度偏低（行高过大），企业后台应提供舒适/紧凑密度。

**优化**：
- 组织树：hover 节点浮现操作图标；树默认展开两级；右侧加「该组织下人员/知识库」摘要卡填充空间（数据已有）。
- 表格统一组件：列排序、斑马纹、行 hover、批量选择条（浮动于底部，Apple 式胶囊）。
- 面包屑与顶栏整合（现 `管理后台 · 组织 · 人员…` 一串静态文本）。

### 4.4 系统设置（06 截图）— 轻度优化

- 三类模型卡片结构清晰，基本保留。优化：`删除` 按钮危险色；「连接正常」改为可点击重测；默认模型加「默认」徽标且主按钮为「设为默认」单选交互；供应商 tab 未走查（P1 复查）。

### 4.5 登录页 — 轻度

- 更名 + GBrain 字标；卡片加阴影层次与 logo；错误提示抖动动画 + CapsLock 提示；预填用户名 `CY` 应移除（生产不应预填账号）。

### 4.6 全局加载/空态

- 现有 `系统正在加载企业数据底座，请稍候...` 出现在 10+ 处（含组件内部 `if (!dbData)` 分支，实际为死代码——`dbData` 常量恒 true，`page.tsx:19`）。清理全部死分支，统一为骨架屏（侧栏骨架 / 列表骨架 / 图谱 canvas 脉冲点）。

## 5. 设计系统沉淀（P2，伴随重构固化）

- 现有 `globals.css` 720 行全局类 + 大量内联样式，建议在改版中同步收敛为 Token + 组件类：色板（现 `--ink/--bg/--evidence` 保留）、8pt 间距、圆角 6/10/14、阴影 2 级、字阶 11/12.5/14/18/28。
- Toast 统一位置（右上角堆叠、带图标与撤销槽）；Modal 统一焦点陷阱（现 `Modal` 仅监听 Esc，无 focus trap）。
- 暗色模式：Token 化后低成本提供（Obsidian 用户群预期高），P2 交付。
